## 🧪 实验环境

- 服务端：Arch Linux 虚拟机 + MariaDB 13（**192.168.1.50:3306，DHCP 动态分配，建议路由器做 MAC 静态绑定**）
- 客户端：Windows 11 + IntelliJ IDEA Database 工具
- 远程管理：OpenSSH（sshd 已启用，ssh cxk@192.168.1.50）
- 内存：1.9G（跑重聚合曾触发 InnoDB Memory pressure event，**灌 100 万行前建议扩到 2~4G**）
- innodb_buffer_pool_size：128M → 建议调至 512M
- 网络模式：桥接（依赖物理局域网网段，**网络变更后虚拟机 IP 需跟随，已改 DHCP 自适应**）
